# 自动控制原理

## 课程概述
研究动态系统的反馈控制：经典控制（频域）与现代控制（状态空间）。

## 主要内容
- 传递函数与方框图、时域分析
- 根轨迹与频域稳定判据（奈奎斯特/波特）
- PID 与校正设计
- 状态空间、能控能观与极点配置
