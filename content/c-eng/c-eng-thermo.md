# 工程热力学

## 课程概述
能量转换的工程科学：热机、制冷与动力循环的效率分析。

## 主要内容
- 热力学定律的工程表述、㶲分析
- 气体与蒸汽动力循环（朗肯、布雷顿）
- 制冷循环与热泵
- 传热学初步（导热/对流/辐射）
