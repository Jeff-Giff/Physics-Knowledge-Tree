# 电子技术基础

## 课程概述
研究半导体器件及其电路：从晶体管到数字逻辑门。

## 主要内容
- 二极管、晶体管（BJT/MOS）与放大电路
- 负反馈、运算放大器与信号调理
- 组合逻辑与时序逻辑、触发器
- A/D 与 D/A 转换

## 先修与后续
通向 [[r-microelectronics]] 与嵌入式/硬件工程。
