# 工程力学

## 课程概述
面向工程的力学：静力学与材料力学（杆件的强度、刚度与稳定性）。

## 主要内容
- 静力学：力系简化与平衡
- 材料力学：拉压弯扭的应力与变形
- 强度理论、压杆稳定
- 疲劳与断裂初步
