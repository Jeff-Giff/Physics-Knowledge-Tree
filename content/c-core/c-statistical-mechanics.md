# 热力学与统计物理

## 课程概述
从微观态的概率假设导出宏观热性质，建立平衡态统计力学的系综理论并初步讨论相变。

## 主要内容
- 微正则、正则与巨正则系综
- 经典理想气体、量子统计（玻色、费米）
- 玻色-爱因斯坦凝聚与费米气体、相变与临界现象初步、涨落理论

## 先修与后续
先修 [[c-thermo]]、[[c-math-methods]]；与 [[c-quantum-mechanics]] 相互支撑（量子统计）。后续为 [[c-solid-state]]、[[c-plasma-intro]]，并通向 [[r-phase]]、[[r-noneq]]、[[r-soft]]、[[r-biophy]]、[[r-complex]] 等研究方向。
