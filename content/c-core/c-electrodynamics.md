# 电动力学

## 课程概述
电磁现象的完整经典场论：从麦克斯韦方程组出发处理静态场、辐射与相对论性表述。

## 主要内容
- 静电与静磁边值问题、多极展开
- 电磁波的传播、导行波与谐振腔
- 电磁辐射、狭义相对论与电动力学的协变形式
