# 理论力学

## 课程概述
以分析力学（拉格朗日、哈密顿形式）重写经典力学，建立贯穿整个理论物理的"作用量—对称性—守恒律"框架。

## 主要内容
- 约束与广义坐标、拉格朗日方程
- 哈密顿正则方程、正则变换、哈密顿-雅可比理论
- 小振动、刚体定点转动、非线性动力学初步

## 先修与后续
先修 [[c-mechanics]]、[[c-math-methods]]。后续为 [[c-electrodynamics]]、[[c-quantum-mechanics]]，并支撑 [[c-gr]]、[[c-fluid]] 与 [[r-nonlinear]]。
