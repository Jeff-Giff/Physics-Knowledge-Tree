# 量子力学

## 课程概述
微观世界的基本理论框架：态、算符、测量与演化，是现代物理几乎所有分支的语言。

## 主要内容
- 波函数与薛定谔方程、一维定态问题
- 算符、表象与测量公设、角动量理论
- 定态微扰论与变分法、自旋与全同粒子、散射初步
