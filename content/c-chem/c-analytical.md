# 分析化学

## 课程概述
研究物质组成与含量的测定：以四大滴定平衡（酸碱/配位/氧化还原/沉淀）为理论核心的定量分析。

## 主要内容
- 误差与数据处理、分析质量控制
- 酸碱、配位、氧化还原、沉淀滴定
- 重量分析法、吸光光度法初步
