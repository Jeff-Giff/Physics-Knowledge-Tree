# 仪器分析

## 课程概述
基于物理仪器的现代分析方法：光谱、色谱、质谱与电化学分析的仪器原理与应用。

## 主要内容
- 紫外-可见/红外/原子吸收与发射光谱
- 气相/液相色谱、毛细管电泳
- 质谱、核磁共振波谱初步、电化学分析
