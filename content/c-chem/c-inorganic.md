# 无机化学

## 课程概述
研究元素及其无机化合物的组成、结构、性质与反应：配位化学是其理论核心。

## 主要内容
- 酸碱理论与非水溶剂、配位化学（晶体场/配位场理论）
- 主族元素化学分区讨论
- 过渡金属与稀土元素化学、无机固体化学初步
