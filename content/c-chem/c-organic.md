# 有机化学

## 课程概述
研究碳氢化合物及其衍生物：结构、命名、反应机理与合成设计，以"官能团 + 机理"为骨架。

## 主要内容
- 立体化学、烷烯炔与芳香烃
- 亲核/亲电取代与加成、消除反应机理
- 醇醛酮羧酸及其衍生物、含氮化合物
- 有机合成设计初步（逆合成分析）
