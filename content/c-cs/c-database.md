# 数据库系统

## 课程概述
研究数据的持久化组织与高效查询：关系模型、SQL、事务与存储引擎。

## 主要内容
- 关系模型与规范化、SQL
- 存储与索引（B+ 树、LSM 树）
- 查询处理与优化
- 事务、并发控制与恢复（ACID）
