# 程序设计基础

## 课程概述
计算机科学的第一课：用一门语言（C/C++/Python）学会把问题变成程序，建立计算思维。

## 主要内容
- 基本语法、数据类型与控制结构
- 函数、数组、指针/引用与内存初步
- 结构化程序设计、调试与测试
- 简单算法与复杂度直觉
