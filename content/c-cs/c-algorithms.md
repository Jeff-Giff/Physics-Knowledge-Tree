# 算法设计与分析

## 课程概述
系统化的算法方法论：分治、动态规划、贪心与 NP 完全性。

## 主要内容
- 渐近分析与递推式
- 分治、动态规划、贪心
- 图算法（最短路、匹配、网络流）
- NP 完全性与近似/随机算法初步
