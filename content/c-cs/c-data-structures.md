# 数据结构

## 课程概述
研究数据的组织方式及其操作效率：表、树、图与散列是全部软件系统的骨架。

## 主要内容
- 线性表、栈与队列
- 树与二叉树、堆、平衡树
- 图结构与遍历、散列表
- 排序与查找、复杂度分析初步
