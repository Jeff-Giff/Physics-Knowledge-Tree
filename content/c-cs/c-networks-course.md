# 计算机网络

## 课程概述
以分层体系（TCP/IP）为主线的网络原理课：从物理层到应用层。

## 主要内容
- 分层模型与协议概念、物理与链路层
- 网络层：IP、路由算法
- 传输层：TCP/UDP、拥塞控制
- 应用层协议与网络安全初步
