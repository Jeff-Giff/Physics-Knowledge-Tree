# 量子场论

## 课程概述
量子力学与狭义相对论的结合：场作为基本对象，粒子是场的激发。

## 主要内容
- 正则量子化、自由场与传播子
- 微扰论与费曼图、量子电动力学
- 重整化初步、规范场论与非阿贝尔规范理论导论
