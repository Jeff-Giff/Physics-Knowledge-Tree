# 计算物理进阶

## 课程概述
面向研究的大规模数值模拟与现代计算方法（本研衔接）。

## 主要内容
- 偏微分方程的高性能求解、并行计算
- 蒙特卡洛与分子动力学进阶
- 机器学习在物理问题中的应用
