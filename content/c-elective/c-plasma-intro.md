# 等离子体物理基础

## 课程概述
研究电离气体的集体行为：单粒子轨道、流体描述与动理论三个层次。

## 主要内容
- 等离子体参量与德拜屏蔽
- 单粒子轨道理论、磁流体力学
- 等离子体波与不稳定性、动理论初步
