# 流体力学

## 课程概述
把质点系力学推广到连续介质，建立流体运动的控制方程与典型流动分析。

## 主要内容
- 连续介质假设、欧拉与纳维-斯托克斯方程
- 理想流体、涡量动力学、势流
- 粘性流动与边界层、湍流现象引论
