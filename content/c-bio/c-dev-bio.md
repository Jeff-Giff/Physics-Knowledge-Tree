# 发育生物学

## 课程概述
研究受精卵如何建成复杂的生物体：细胞命运决定、图式形成与形态发生。

## 主要内容
- 受精与早期胚胎发育、细胞命运与分化
- 图式形成与体轴建立、形态发生素
- 器官发生、干细胞与再生
- 演化发育生物学（Evo-Devo）初步
