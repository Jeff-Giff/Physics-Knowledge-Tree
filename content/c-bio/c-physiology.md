# 生理学

## 课程概述
研究生物体各系统的功能及其调节：以人和动物生理为主干的整合性课程。

## 主要内容
- 神经与肌肉生理、感觉系统
- 循环、呼吸、消化与排泄
- 内分泌与生殖、体温与内环境稳态
- 植物生理概要
