# 分子生物学

## 课程概述
研究遗传信息的存储、复制与表达：中心法则是其纲领。

## 主要内容
- DNA 复制、修复与重组
- 转录与转录调控（操纵子、表观遗传）
- 翻译与翻译后加工
- 基因工程基本技术（克隆、PCR、测序原理）
