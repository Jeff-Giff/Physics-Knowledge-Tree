# 偏微分方程

## 课程概述
研究含多元未知函数偏导数的方程：波动、热传导与位势三大经典方程及其现代理论。

## 主要内容
- 一阶方程与特征线法、分离变量法
- 波动方程、热方程、拉普拉斯方程
- 格林函数、极值原理、弱解初步

## 先修与后续
通向 [[r-pde-research]]；物理中对应 [[c-electrodynamics]]、[[c-fluid]] 的基本方程。
