# 数值分析

## 课程概述
研究连续数学问题的离散近似算法：误差、收敛性与稳定性分析。

## 主要内容
- 插值与逼近、数值积分与微分
- 线性方程组直接法与迭代法、特征值计算
- 非线性方程求根、常微分方程数值解

## 先修与后续
通向 [[r-scientific-computing]]，支撑一切计算密集型研究。
