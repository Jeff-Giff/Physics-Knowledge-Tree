# 通信原理

## 课程概述
研究信息可靠传输的基本原理：调制解调、信道与最佳接收。

## 主要内容
- 模拟与数字调制（AM/FM、ASK/PSK/QAM）
- 信源与信道模型、噪声中的最佳接收
- 信道编码初步（分组码、卷积码）
- 同步与复用
