# 数字信号处理

## 课程概述
研究离散时间信号的数字处理算法：滤波器设计与快速变换是两大支柱。

## 主要内容
- 离散傅里叶变换与 FFT
- 数字滤波器设计（FIR/IIR）
- 多采样率处理与小波初步
- 谱估计初步
