# 数字图像处理

## 课程概述
研究图像的数字化处理：增强、复原、分割与压缩，是计算机视觉的经典底层。

## 主要内容
- 空域增强（直方图、滤波）与频域处理
- 图像复原（去噪、去模糊）与重建
- 边缘检测、分割与形态学
- 图像压缩标准（JPEG）初步
